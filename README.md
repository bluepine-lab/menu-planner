# 献立

> 個人の試作・初版です。動作は参考情報で、保証はしません。

主菜・副菜・汁を組み合わせた数日分の献立と、材料を合算した売り場ごとの買い物リストを作ります。季節、使いたい食材、避けたい食材、手間の少なさを指定できます。個人の試作の初版で、参考情報です。

## 先に知っておいてほしいこと

- **料理の選び方と材料の合算は付属のスクリプト(Python 3)がします。** AIの暗算ではありません。Pythonが無い場合は簡易モードになりますが、量は目安で、ずれることがあります
- 追加のライブラリは要りません(Pythonに最初から付いているものだけで動きます)
- 入っているのは**家庭料理45品の小さな一覧**(主菜・副菜・汁・行事食)です。レシピの詳しい手順は入っていません
- **栄養計算はしません。** 「バランスがよい」とは言いません
- **アレルギーや医療上の食事制限(糖尿病・腎臓病・離乳食など)には対応しません。** 避けたい食材は指定できますが、結果に出る「含まれるアレルゲン」は目安です。必ず実際の商品表示を確認してください。医師や栄養士の指示がある人は、その指示を優先してください
- 買い物リストの量は目安です。調味料と米は常備品として含めていません。冷蔵庫の在庫は見えないので、買う前に確認してください
- `SKILL.md` に対応しているAIツールで使える作りにしていますが、**動作確認は Claude Code(Windows)だけです。** ほかのAIツール・Mac・Linux は動く想定で、確認していません

## できること

- 既定は3日分・2人分・手間ふつう。聞かれるのは「避けたい食材やアレルギーはありますか」の1問だけです
- 季節に合う料理を選び、同じ主材料が続かないようにします
- 使いたい食材を優先できます(例: 「キャベツを使いたい」)
- 材料を合算して、売り場ごと(野菜・果物 / 肉・魚 / 卵・乳・豆腐 / 乾物・その他)の買い物リストにします
- 表示は文字の枠、または自分のPCで開くHTMLページです

## ほかのスキルとの連携(入っている時だけ)

同じ作者の別スキルが同じ場所に入っていると、その結果を読んで使います。入っていなくても単独で動きます。

- `今日は何の日`: 行事食を献立に反映する
- `記念日`: 誕生日などの日に、お祝いのメニューを提案する
- `気分日記`: 直近の気分が低めの週は、手間の少ない献立にする(理由は口に出しません)

連携の時は、これらのスキルの `scripts/` 内のスクリプトを、このスクリプトが呼び出します。呼び出すのは同じスキル置き場(`~/.claude/skills/` など)にあるものだけです。

## 安全性について(何をするか、全部書きます)

「安全です」と言い切るより、何をするかを並べます。気になる人はコードを読んでください(スクリプトは `scripts/menu.py` の1本、料理の一覧 `scripts/dishes.json`、ページのひな形 `scripts/page.html` です)。

**やること**
- 料理の一覧から、条件に合うものを選んで表示する
- 表示の好みの変更を頼んだ時だけ、`~/.claude/献立/表示設定.md` に変更点を書く
- 連携するスキルが入っていれば、そのスクリプトを呼び出して結果を読む(上の節)

**やらないこと**
- **インターネットへの通信は、スクリプトからは一切しません。** 外へ送るための仕組み(urllib・requests・socket など)は使っていません
- 連携以外で、ほかのファイルを読み書きしません

**ひとつだけ注意**
- 「ページで出す」機能のひな形(`scripts/page.html`)は、見た目のために Google Fonts(フォント)を読み込みます。ページを開く時にだけ、フォントの取得で外部への通信が起きます

**消す** → スキルのフォルダと、`~/.claude/献立/` フォルダを削除すれば、すべて消えます

## 入れ方

このフォルダの内容(`SKILL.md` と `scripts/`)を、お使いのAIツールのスキル置き場に `献立` という名前のフォルダで置きます。Claude Code なら `~/.claude/skills/献立/` です。

あとは「今週の献立」と話しかけます。

## 使い方

| やりたいこと | 話しかけ方 |
|---|---|
| 数日分の献立を出す | 「今週の献立」「夕飯なにがいい?」 |
| 買い物リストを作る | 「買い物リストを作って」 |
| 条件を変える | 「4人分で」「キャベツを使って」「手間を減らして」 |
